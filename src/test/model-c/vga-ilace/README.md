# VGA ILACE

Make an .F16 VGA font suitable for interlaced display - converted from the 
original VGA8.F16 from https://github.com/viler-int10h/vga-text-mode-fonts/tree/master/FONTS/PC-IBM
using the script f16totext.pl. The font was manually edited to avoid lone 
pixels or horizontal lines that would cause excessive flicker.

## VGA8I.F16.txt

This font has extra pixels above and below the regular top/bottoms of capitals
and numerals.
